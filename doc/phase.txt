Main is project ko roughly 12 phases me divide karunga:

phase 1. MT5 Integration Layer — MT5 terminal connection, account/market data, OHLCV/ticks, spreads, positions, orders, SL/TP, execution status aur reconnect/error handling.
phase 2. Market Data Engine — multi-timeframe candles, tick data, indicators, volatility, sessions, spread/slippage, economic-event flags aur historical database. Raw data ko kabhi overwrite nahi karna.
phase 3. Feature Engine — trend, momentum, ATR/volatility, market structure, support/resistance, liquidity proxies, session behavior, higher-timeframe context aur trade-cost features. AI ko sirf RSI/MACD jaise indicators par dependent nahi banana.
phase 4. Market Regime Engine — market ko Trend, Range, High Volatility, Low Volatility, Breakout-type conditions jaise regimes me classify karega. Ek hi strategy har regime me use karna generally robust approach nahi hai.
phase 5. Strategy/Signal Engine — AI output ideally LONG / SHORT / NO TRADE ke saath confidence aur proposed SL/TP de. Final order AI directly place na kare; signal Risk Engine se pass ho.
phase 6. Risk Management Engine — sabse critical module. Max risk/trade, daily loss limit, max drawdown, max simultaneous exposure, spread/slippage filters, cooldown, max trades/day aur emergency kill switch AI se independent rahenge. AI in hard limits ko override nahi kar sakega.
phase 7. Execution Engine — approved signal → position sizing → pre-trade validation → MT5 order → execution confirmation → position monitoring → partial/SL/TP/trailing logic → close → complete execution record.
phase 8. Trade Memory System — har trade ke liye entry-time market snapshot, features, regime, AI decision, confidence, entry/SL/TP, actual fills, spread/slippage, exit reason, P&L aur MFE/MAE store honge. Ye system ka long-term "experience database" hoga.
phase 9. AI Learning Engine — closed trades ko simply profit = good / loss = bad label mat dena. Model ko decision quality, risk-adjusted outcome, market regime, transaction cost aur counterfactual context evaluate karna chahiye. Warna random profitable trades se bhi wrong behavior learn ho sakta hai.
phase 10. Research & Training Pipeline — Production Model → New Data → Dataset Builder → Candidate Model → Backtest → Walk-forward → Out-of-sample → Stress/Monte-Carlo tests → Paper Trading → Promotion. Live model ko directly self-train/self-deploy karne ki permission nahi deni chahiye.
phase 11. AI Model Registry / Brain Versions — Brain v1, v2, v3... Har version ke saath training period, dataset version, features, parameters, backtest metrics, live/paper metrics aur deployment date save ho. New model old model se objectively validate ho; performance degrade ho to rollback.
phase 12. Dashboard & Control Center — MT5 connection, equity/balance, open positions, daily P&L, drawdown, AI confidence, current regime, recent decisions, model version, learning statistics, risk status, backtest/paper/live modes aur Emergency Stop.
